# 用户操作说明

## 普通用户

1. 使用独立用户名和密码登录，不再使用身份证号作为登录标识。
2. 在搜索页输入出发机场、到达机场、日期和舱位。
3. 若有余票，点击“创建待支付订单”。
4. 在“我的订单”中查看订单状态：
   `PENDING_PAYMENT / PAID / EXPIRED / REFUNDED`。
5. 对待支付订单执行“模拟支付”，系统只保存脱敏付款账号和哈希值。
6. 如需取消出行，可对已支付订单执行退票。
7. 若航班售罄，可加入候补队列；候补释放后重新搜索并下单。

## 管理员

1. 使用独立管理员账号登录。
2. 维护城市、机场、飞机、航线等基础数据。
3. 配置航班模板并批量生成未来排班。
4. 创建或维护固定场次特价票活动。
5. 查看全网订单、支付状态和审计日志。
6. 在航班异常时执行取消航班与批量退款。
