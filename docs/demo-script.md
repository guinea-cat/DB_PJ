# 航空票务系统 Demo 操作说明

本文档面向当前课程版演示环境，默认系统已经通过 `docker compose up -d` 或本地脚本成功启动。

## 1. 演示前确认

先确认服务已正常启动：

```powershell
docker compose ps
curl.exe http://127.0.0.1:8000/health
```

期望结果：

- 后端健康检查返回 `{"status":"ok","database":"ok"}`
- 前端地址：`http://127.0.0.1:5173`
- Swagger 地址：`http://127.0.0.1:8000/docs`

## 2. 可用账号

- 普通用户 1：`alice01 / user123`
- 普通用户 2：`bob01 / user123`
- 管理员：`admin / admin123`

## 3. 当前推荐演示时间窗口

- 用户搜索默认窗口：`2030-01-13` 到 `2030-01-26`
- 管理员排班生成窗口：`2030-01-27` 到 `2030-02-02`

说明：

- 用户窗口中的演示航班已经准备好，便于直接演示搜索、下单、支付和退票。
- 管理员窗口适合现场点击“生成排班”，展示模板转具体航班的过程。

## 4. 推荐演示顺序

### 场景 1：普通用户搜索航班

1. 打开前端页面。
2. 使用 `alice01 / user123` 登录。
3. 搜索 `SHA -> KMG`，日期选择 `2030-01-15`，舱位选择 `Y`。
4. 展示系统返回多条可售航班，并显示价格来源字段。
5. 说明普通票会展示阶梯定价结果，特价票会展示“特价票”标签。

### 场景 2：特价票与普通票定价对比

1. 在搜索结果中展示命中特价活动的航班。
2. 说明价格来源为 `SPECIAL` 时，最终价直接取活动价。
3. 再展示未命中特价活动的航班。
4. 说明价格来源为 `STANDARD` 时，采用基础价、航班折扣、用户折扣和余票阶梯系数联合计算。

### 场景 3：待支付、模拟支付与退票

1. 选择一条有余票的航班，点击“创建待支付订单”。
2. 打开“我的订单”，展示订单状态为 `PENDING_PAYMENT`，并显示支付截止时间。
3. 点击“模拟支付”，输入付款方式和付款账号。
4. 展示订单状态变为 `PAID`，且系统只显示脱敏后的支付账号。
5. 对已支付订单执行退票，展示订单状态变为 `REFUNDED`，库存被返还。

### 场景 4：候补释放

1. 让 `bob01 / user123` 登录另一窗口。
2. 选择同一条座位紧张或已售罄的航班加入候补。
3. 回到 `alice01` 页面执行退票。
4. 再查看 `bob01` 的候补记录，展示状态变为 `RELEASED`。
5. 说明当前版本保留“释放通知，不自动购票”的简化规则。

### 场景 5：管理员生成排班与管理特价票

1. 使用 `admin / admin123` 登录。
2. 在“排班控制室”中选择模板和日期范围，点击生成排班。
3. 展示生成结果摘要，包括匹配日期、生成日期和跳过日期。
4. 进入“特价票活动”区域，新建或编辑固定场次特价票。
5. 说明特价票采用“固定航班日期 + 舱位 + 区间 + 限量配额”的轻量化课程方案。

### 场景 6：管理员查看订单与审计

1. 打开管理员订单页。
2. 展示乘客姓名、身份证号和支付账号均为脱敏值。
3. 展示订单状态、支付状态、价格来源等交易留痕信息。
4. 打开审计日志，说明系统记录关键状态变更但不写入明文敏感信息。

## 5. Swagger 备用演示

如果前端临时不可用，可直接使用 Swagger：

- `POST /auth/login`
- `GET /auth/me`
- `GET /flights/search`
- `GET /flights/search/range`
- `POST /tickets/purchase`
- `POST /payments/{payment_id}/confirm`
- `POST /tickets/{ticketNo}/refund`
- `GET /me/orders`
- `POST /waitlists`
- `POST /admin/schedules/generate`
- `POST /admin/schedules/{flightNo}/{date}/cancel`
- `GET /admin/orders`
- `GET /admin/special-fares`

## 6. 停止与重置

停止容器：

```powershell
docker compose down
```

如需彻底清空数据并重新初始化：

```powershell
docker compose down -v
docker compose up -d
```
